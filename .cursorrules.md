
# DX7 RP2350 Project Rules


## AI Behavior
- Never output full files if only 2-3 lines need to be changed. Use concise diffs or partial code blocks.
- When generating hardware-specific code (PIO, DMA, Clocks, Dual-core), strictly use Pico SDK 2.0 hardware libraries, not bare-metal register shifting, unless explicitly asked.
- Avoid wrappers, write clean C/C++.

## Контекст проекта
- Embedded C for Raspberry Pi RP2350 (Pico 2)
- SDK: Raspberry Pi Pico SDK 2.0 (supports ARM Cortex-M33 and RISC-V Hazard3).
- Build System: CMake + Ninja. Do not suggest Makefiles.
- Yamaha DX7 II FD upgrade
- TFT LCD ST7789, MPR121 touch, SD card

## Стиль кода
- Используйте snake_case для функций и переменных
- Префиксы: ui_, sys_, debug_, mpr_
- Все координаты UI должны быть в процентах или макросах из hw_config.h
- Избегайте hardcoded значений (магических чисел)

## Ограничения железа
- RAM: 520KB SRAM
- Flash: 4MB QSPI
- CPU: 150MHz dual-core Cortex-M33

## Правила отладки
- Все критические операции логируйте через debug_log_write()
- Используйте DBG_LOG(), DBG_WARN(), DBG_ERR() макросы
- Не используйте printf() в production коде

## Структура файлов
- core/ - драйверы железа
- services/ - бизнес-логика
- modes/ - состояния FSM
- mapping/ - профили контроллеров
